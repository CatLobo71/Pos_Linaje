Importar Ventas Históricas desde Excel

1. Selecciona el archivo

Sube un archivo Excel (.xlsx, .xls o .xlsm) que tenga una hoja con las columnas Ticket, Fecha, Hora, ESTATUS, Producto, TAMAÑO, SABORES, GUISADO 1-4, Cantidad, Importe, Tipo Servicio, Tipo de Pago (el mismo formato que la hoja "ACUMULADO VENTAS"). Las ventas se agregan como ventas retroactivas (quedan marcadas como históricas) y no afectan el folio de tus ventas del día a día. Puedes usar esta pantalla cada vez que tengas un nuevo archivo que importar (por ejemplo, el de 2024 y 2025).
